# Recipes

Worked examples for the jobs that come up most. Python shown; Node and PHP use the same
method names in `camelCase`.

## Customer dashboard in one screen

```python
summary  = client.account.get_summary()["total"]          # counts of each thing
balance  = client.billing.get_balance()["details"]
services = client.services.list(filters={"hide_cancelled": 1})["services"] or []
domains  = client.domains.list()["domains"] or []
due      = client.billing.list_invoices_due()["invoices_due"] or []
```

`get_summary()` is one call and gives you the four counters — use it for the header
instead of fetching every list just to count them.

## Walk a paginated list

```python
page = 0
while True:
    result = client.billing.list_invoices(page=page, perpage=50, orderby="date|DESC")
    for invoice in result["invoices"] or []:
        yield invoice
    meta = result.get("page") or {}
    if not result["invoices"] or meta.get("current", 1) >= (meta.get("pages") or 1):
        break
    page += 1
```

`page` starts at 0 and the response echoes it back one-based in `page.current` — that
asymmetry is the usual source of duplicate-last-page bugs.

## Check a domain and order it

```python
availability = client.domains.lookup(name="example.vn")      # no auth needed
if availability["avaliable"]:                                 # note the API's spelling
    cart  = [{"product_id": tld_product_id, "cycle": "1", "domain": "example.vn"}]
    quote = client.cart.quote(items=cart)["summary"]
    # show quote["total"] (tax included) and get the customer's confirmation, then:
    order = client.cart.order(items=cart)
```

TLD product ids come from `client.cart.list_domain_tlds_v2()`. `cart.order` is the only
ordering endpoint — it takes hosting, VPS, domains and SSL in the same call.

## Manage DNS records

```python
zones = client.dns.list_zones_all()["zones"] or []
zone  = zones[0]
sid, zid = zone["service_id"], zone["domain_id"]

records = client.dns.get_zone(sid, zid)["records"]           # dict keyed by index
created = client.dns.create_record(sid, zid, name="www", type="A",
                                   content="203.0.113.10", ttl=3600)
client.dns.update_record(sid, zid, record_id, name="www", type="A",
                         content="203.0.113.11", ttl=3600)
client.dns.delete_record(sid, zid, record_id)
```

`create_record` does not return the new id reliably — read the zone back and match on
name/type if you need it.

Do **not** call `client.dns.reset_zone_password()` to "check" anything: it generates a
new password every time.

## Drive a VM safely

```python
import time

def wait_idle(sid, vmid, timeout=180):
    """VM actions are asynchronous — a second one while the first runs is rejected."""
    deadline = time.time() + timeout
    while time.time() < deadline:
        status = client.vms.get(sid, vmid)["vm"]["status"]
        if status in ("running", "stopped"):
            return status
        time.sleep(5)
    raise TimeoutError(f"VM {vmid} still busy")

client.vms.stop(sid, vmid);  wait_idle(sid, vmid)
client.vms.start(sid, vmid); wait_idle(sid, vmid)
```

Snapshot names are generated by the platform, so read them back before deleting:

```python
client.vms.create_snapshot(sid, vmid)
raw = client.vms.list_snapshots(sid, vmid)["snapshots"] or {}
for snapshot in (raw.values() if isinstance(raw, dict) else raw):
    client.vms.delete_snapshot(sid, vmid, snapshot["name"])
```

## Download a PDF or a certificate

```python
response = client.request("GET", "/clientarea/downloadprofile", raw=True)
open("profile.pdf", "wb").write(response.content)            # .content is bytes
```

`GET /invoice/{id}/pdf` is different — it returns JSON with the PDF base64-encoded in
the `invoice` field.

## Proxy the API from your own backend

Forward the end user's address so Tino's rate limiting and the token's `ip` claim see
the real client:

```python
client = TinoClient(
    token=session["tino_token"], refresh_token=session["tino_refresh"],
    default_headers={"X-Real-IP": request.remote_addr,
                     "X-Forwarded-For": request.remote_addr},
    on_token_refresh=lambda t, r: session.update(tino_token=t, tino_refresh=r),
)
```
